## Featured projects

### 🤖 AI applications & engineering

**[5G Network Diagnostics RAG Assistant](https://github.com/fredrik-nguyen-labs/Telecom-RAG)**  
[Live demo](https://telecom.fnsystems.dev) · [Source code](https://github.com/fredrik-nguyen-labs/Telecom-RAG)  
A full-stack assistant for telecom questions and KPI diagnosis, combining LangGraph-based routing, Supabase hybrid retrieval, Cloudflare Workers AI, and cited technical evidence. Built with **React, FastAPI, Python, and PostgreSQL/pgvector**.

### 🔬 Machine learning & research

**[One-Step Flow Matching for Channel Estimation](https://github.com/FredrikNguyen/Channel-Estimation-via-One-Step-Flow-Matching-Based-Generative-Models)**  
My KTH master's thesis, carried out with Huawei Sweden R&D. Explores low-latency generative channel estimation in pilot-contaminated MIMO-OFDM systems, including flow matching, consistency-style objectives, and distillation. **PyTorch · Generative ML · Wireless communications**

**[Movie Genre Data Analysis & Prediction](https://github.com/FredrikNguyen/Movie-Genre-Data-Analysis)**  
[Interactive project website](https://epfl-ada.github.io/ada-2024-project-alpacadreamagency/) · [Source code](https://github.com/FredrikNguyen/Movie-Genre-Data-Analysis)  
An EPFL data-science project exploring what movie metadata and summaries reveal about genre, and how those signals can be used for genre classification. **Data analysis · NLP · Machine learning**

**[Road Segmentation from Aerial Imagery](https://github.com/FredrikNguyen/road_segmentation_project)**  
An EPFL computer-vision project using U-Net-based semantic segmentation and image augmentation to identify roads in aerial images. **PyTorch · Computer vision · Image segmentation**

**[Emotion Classification in Audio](https://github.com/FredrikNguyen/Comparative-Analysis-of-Deep-Learning-Architectures-for-Emotion-Classification-in-Audio)**  
A comparative study of CNN, LSTM, hybrid, and wav2vec-based approaches for speech emotion recognition. **Deep learning · Audio · Representation learning**
